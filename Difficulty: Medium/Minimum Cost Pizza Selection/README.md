<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong style="font-size: 18px;">Input:</strong> </span><span style="font-size: 18px;">x = 16, s = 3, m = 6, l = 9, cs = 50, cm = 150, cl = 300</span>
<span style="font-size: 18px;"><strong><span style="font-size: 18px;">Output:</span> </strong></span><span style="font-size: 18px;">300</span>
<span style="font-size: 18px;"><strong><span style="font-size: 18px;">Explanation:</span> </strong></span><span style="font-size: 18px;">We want </span><span style="font-size: 18px;">at least</span><span style="font-size: 18px;"> 16 sq. units of Pizza. <br></span><span style="font-size: 18px;">One unit of each s, m and l = 3 + 6 + 9 = 18 sq units, Cost = 500. <br></span><span style="font-size: 18px;">6 units of s = 18 sq units, Cost = 300 <br>2 units of l = 18 sq units, Cost = 600</span><span style="font-size: 18px;"> etc. <br>Of all the Arrangements, Minimum Cost is Rs. 300.</span></pre>
<pre><span style="font-size: 18px;"><strong style="font-size: 18px;">Input:</strong> </span><span style="font-size: 18px;">x = 10, s = 1, m = 3, l = 10, cs = 10, cm = 20, cl = 50</span>
<span style="font-size: 18px;"><strong><span style="font-size: 18px;">Output:</span> </strong></span><span style="font-size: 18px;">50</span>
<span style="font-size: 18px;"><strong>Explanation: </strong></span><span style="font-size: 18px;">Of all the Arrangements possible, Minimum Cost is Rs. 50.</span></pre>
